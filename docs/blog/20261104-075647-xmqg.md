## 为什么选择 SVG 做交互动效

SVG 作为矢量格式，在缩放时不会失真，且文件体积通常小于同等视觉效果的位图。更重要的是，SVG 的每个图形元素都是 DOM 节点，可以直接用 CSS 或 JavaScript 操控，这为交互动效提供了天然基础。与 Canvas 相比，SVG 的声明式结构更易维护，适合图标、图表和装饰性动画。在实战中，建议优先将 SVG 内联到 HTML 中，而非通过 img 标签引入，这样才能用脚本访问内部元素。

## 用 CSS 实现轻量动效

对于悬停变色、路径描边、渐变填充等常见效果，CSS 是首选。利用 `transition` 和 `@keyframes` 可以完成大部分交互动画。例如，通过 `stroke-dasharray` 与 `stroke-dashoffset` 配合过渡，能实现线条绘制效果；使用 `transform` 对 SVG 分组进行位移或旋转时，注意设置 `transform-box: fill-box` 和 `transform-origin` 以控制变换基准点。需要避免对 `d` 属性做 CSS 过渡，因为浏览器支持不一致，应改用 JavaScript 或 SMIL（不推荐用于生产）。

## JavaScript 控制复杂交互

当动效需要响应用户输入、滚动位置或数据变化时，JavaScript 更合适。推荐使用 `requestAnimationFrame` 驱动动画循环，避免直接修改样式导致布局抖动。对于路径变形，可以借助 Web Animations API 对 `d` 属性做插值，但需确保路径命令结构一致。事件处理上，利用事件委托监听 SVG 根元素，通过 `event.target` 判断具体图形，减少监听器数量。若动效涉及大量元素，考虑使用 `will-change` 提升合成层，但不要滥用。

## 性能与可访问性要点

SVG 动效同样需要关注性能。优先使用 `transform` 和 `opacity` 做动画，它们不会触发重排。对于复杂滤镜（如 `feGaussianBlur`），尽量静态化或降低使用频率。可访问性方面，为装饰性 SVG 添加 `aria-hidden="true"`，为功能性图形提供 `<title>` 和 `<desc>`。同时，尊重用户的 `prefers-reduced-motion` 设置，通过媒体查询关闭非必要动画。最后，将 SVG 代码压缩并移除编辑器生成的冗余属性，能进一步减小体积。

通过以上方法，你可以在 PHP Demo Blog 这类轻量项目中快速集成高质量的 SVG 交互动效，兼顾视觉表现与运行效率。
