## 为什么选择 SVG 做交互动效

SVG 作为矢量格式，在缩放时不会失真，且每个图形元素都是 DOM 节点，可直接用 CSS 或 JavaScript 控制。相比位图动画，SVG 动效的文件体积更小，尤其适合图标、插画和图表类交互。在 PHP Demo Blog 这类轻量项目中，用 SVG 实现加载动画或按钮反馈，能避免引入重型动画库。

实战中，建议将 SVG 内联到 HTML 中，而非通过 img 标签引用。内联后，CSS 选择器可以直接命中 path、circle 等元素，JavaScript 也能通过 querySelector 获取节点并绑定事件。例如，一个汉堡菜单图标可以拆分为三条 line，通过切换 class 控制旋转与透明度，实现平滑的展开收起效果。

## 用 CSS 驱动基础动效

CSS 动画是 SVG 交互动效的首选方案，性能好且易于维护。关键是把动画属性限定在 transform 和 opacity 上，避免触发重排。对于路径描边动画，可以利用 stroke-dasharray 和 stroke-dashoffset 配合 transition，实现线条绘制的视觉效果。

具体做法是：先获取路径总长度（可通过 JavaScript 的 getTotalLength() 方法），将 stroke-dasharray 设为该长度，stroke-dashoffset 也设为该长度，然后在交互时把 dashoffset 过渡到 0。这样点击按钮时，图标线条会像被“画”出来一样。注意在 CSS 中为 transition 指定具体属性，并添加 will-change 提示浏览器优化。

## JavaScript 增强交互与状态管理

当动效需要根据用户输入或数据状态变化时，JavaScript 不可或缺。常见场景包括：鼠标悬停时改变图形颜色、点击切换播放状态、根据滚动位置触发动画。建议使用事件委托，在 SVG 根元素上监听事件，通过 event.target 判断具体图形，减少监听器数量。

对于复杂序列动画，可以使用 Web Animations API，它提供了比 CSS 更灵活的时间控制。例如，用 element.animate() 定义关键帧，并返回 Animation 对象，便于暂停、取消或调整播放速率。在 PHP Demo Blog 的 JSON API 示例中，可以用这种方式展示数据加载的进度反馈，提升用户体验。

## 性能与可访问性要点

SVG 动效的性能瓶颈通常来自过多的 DOM 节点和复杂的滤镜效果。优化策略包括：合并重复路径、移除不必要的分组、避免在动画中使用 filter 和 mask。同时，为动画元素添加 aria-hidden="true"，避免屏幕阅读器重复朗读装饰性内容；对于有意义的交互图标，则提供 role="img" 和 aria-label。

最后，尊重用户的 prefers-reduced-motion 设置，通过媒体查询关闭非必要动画。在移动端，注意触摸事件与鼠标事件的兼容处理，使用 pointer 事件统一交互逻辑。遵循这些实践，SVG 交互动效既能保持视觉吸引力，又不会拖累页面性能。
